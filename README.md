# Chopsticks-Dashboard
 This repository is a companion website for a Google Chat Webhook. This website is used to answer all of your questions that you have. PLEASE NOTE THIS IS FOR A CUSTOM WEBWOOK
## Current Features
This Website currently features:
- Login System (Creating an Account requires manual application to a developer)
- Leaderboard (With Sync to actual data)
- Fish Library
- Card Library
- All Shop Items library
- Commands Library
- Release Notes (Not all of the Webhook versions is recorded)
- Settings (Currently in Beta, with working light/dark theme)
